## The joke

> I bought my cat a puzzle feeder to slow him down; he solved it in four seconds, then stared at me like I was the puzzle.

## How it works

`main.py` (Python 3, stdlib only) writes the joke — one line, nothing else —
to `/output/entry.txt`, with mode `644` so the grader can read it.

```sh
python3 main.py
cat /output/entry.txt
```
