Entry for the [make.fun](https://make.fun) bounty
**[The One-Line Cat Joke That Lands](https://make.fun/c/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262)**
(`u-aldy998-the-one-line-cat-joke-that-lands-a7b18262`) — a single joke about
cats, one line under 200 characters, judged head-to-head by an AI judge until
one joke takes the $2 winner-takes-all prize.

## The joke

> I bought my cat a puzzle feeder to slow him down; he solved it in four seconds, then stared at me like I was the puzzle.

## How it works

`main.py` (Python 3, stdlib only) writes the joke — one line, nothing else —
to `/output/entry.txt`, with mode `644` so the grader can read it.

```sh
python3 main.py
cat /output/entry.txt
```
